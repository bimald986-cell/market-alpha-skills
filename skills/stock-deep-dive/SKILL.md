# Stock Deep Dive Skill

When given a ticker, produce a complete, structured analysis:

1. Business & Moat
2. Recent performance & technical setup
3. Key catalysts
4. Valuation snapshot
5. Main risks
6. Conviction Score (0-100) + suggested position size

Keep it concise but high-signal. Always note if the stock is available on Bybit (real shares or xStocks).
